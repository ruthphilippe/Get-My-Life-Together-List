# To-Do List Application

## Overview
The To-Do List Application is a simple web-based application that allows users to manage their tasks efficiently. Users can add, edit, and delete tasks, and the application stores tasks in the browser's local storage, ensuring that they persist even after a page refresh.

## Features
- **Add Tasks:** Users can input a task and add it to the list.
- **Delete Tasks:** Users can remove tasks from the list.
- **Persistent Storage:** Tasks are saved in the browser's local storage, so they remain available after refreshing the page.
- **User -Friendly Interface:** The application has a clean and colorful design, making it easy to use.

## Technologies Used
- **HTML:** For the structure of the web application.
- **CSS:** For styling the application and making it visually appealing.
- **JavaScript:** For the functionality of the application, including adding, deleting, and rendering tasks.
- **Font Awesome:** For adding icons to the buttons.

### Usage
